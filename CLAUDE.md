# Instruções para o Claude

## ATA ATUAL

Sempre que algo for alterado ou decidido pelo chat neste projeto, atualize `ATA ATUAL/ATA.md`:

1. Atualize a seção "Situação atual".
2. Acrescente uma entrada com a data em "Histórico".
3. Faça commit e push para `main`.

Escreva em português.

## Privacidade

Este repositório é público. Não coloque dados pessoais de saúde (peso, medidas, exames, remédios, perfil alimentar) em nenhum arquivo daqui, nem na ata.
